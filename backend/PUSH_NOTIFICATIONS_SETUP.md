# Настройка Push-уведомлений

## Требования

1. **VAPID ключи** - необходимы для работы Web Push API
2. **Service Worker** - должен быть зарегистрирован на frontend
3. **HTTPS** - push-уведомления работают только через HTTPS (или localhost для разработки)

## Генерация VAPID ключей

Для генерации VAPID ключей используйте команду:

```bash
npx web-push generate-vapid-keys
```

Это создаст пару ключей:
- **Public Key** - используется на frontend
- **Private Key** - используется на backend (секретный)

## Настройка переменных окружения

### Backend (.env)

Добавьте следующие переменные:

```env
VAPID_PUBLIC_KEY=your_public_key_here
VAPID_PRIVATE_KEY=your_private_key_here
VAPID_SUBJECT=mailto:admin@example.com
```

### Frontend (.env)

Добавьте:

```env
VITE_VAPID_PUBLIC_KEY=your_public_key_here
```

## Функциональность

### Уведомления для Админов и Менеджеров

- **Создание заказа** - уведомление отправляется всем админам и менеджерам, связанным с баром
- **Создание прихода** - уведомление отправляется всем админам и менеджерам, связанным с баром
- **Создание списания** - уведомление отправляется всем админам и менеджерам, связанным с баром
- **Выручка за день** - отправляется в 23:00 (Asia/Tashkent)
  - Админы получают выручку со всех баров
  - Менеджеры получают выручку только со своих баров

### Уведомления для Работников

- **15:00** - "Не забудьте сделать заказ еды и закуп" (на русском и узбекском)
- **22:50** - "Напишите сегодняшнюю кассу" (на русском и узбекском)

## Cron-задачи

Все cron-задачи настроены на часовой пояс **Asia/Tashkent (UTC+5)**:

- `0 15 * * *` - Напоминание о заказе еды (15:00)
- `50 22 * * *` - Напоминание о кассе (22:50)
- `0 23 * * *` - Отправка выручки (23:00)

## API Endpoints

### POST /notifications/register

Регистрация токена устройства для push-уведомлений.

**Body:**
```json
{
  "token": "string (JSON subscription object)",
  "deviceInfo": "string (optional)"
}
```

### DELETE /notifications/unregister

Удаление токена устройства.

**Body:**
```json
{
  "token": "string"
}
```

## Service Worker

Service Worker должен быть размещен в `frontend/public/sw.js` и автоматически регистрируется при инициализации приложения.
